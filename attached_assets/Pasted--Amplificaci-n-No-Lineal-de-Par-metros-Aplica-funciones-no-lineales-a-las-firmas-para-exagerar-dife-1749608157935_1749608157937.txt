def generate_palette_from_signature(fibonacci_signature):
    seed = int(fibonacci_signature * 1000) % 360
    return [f"hsl({(seed + i*30)%360}, 80%, 60%)" for i in range(5)]
Cada gen tiene una huella cromática única. Podés incluso usar gradient maps.
